## 📌 Project Overview
This repository contains the completed individual practical assignment #5, dedicated to mastering the fundamentals of client-side web development using JavaScript. The project demonstrates practical application of Document Object Model (DOM) manipulation, event handling paradigms, form interactions, and dynamic state management using native JavaScript without external libraries or frameworks.

---

## 📂 Project Structure & Navigation
The application is structured as a multi-page website featuring a persistent navigation bar (`navbar`) for seamless switching between tasks:

* **`index.html` (Part 1 - Introduction to JS):** Covers basic syntax, variable declarations (`let`, `const`), primitive data types (strings, numbers, booleans), arithmetic operators, string concatenation, and outputting data to the browser's Developer Console and alert pop-ups.
* **`dom.html` (Part 2 - DOM Manipulation):** Implements element selection, dynamic text content updates, runtime inline style modifications (background colors and font scaling), and programmatic creation/removal of DOM nodes (`<li>` elements inside an unordered list).
* **`events.html` (Part 3 - Events & Calculator):** Showcases advanced event listeners including mouse events (`mouseover`, `mouseout`), keyboard input tracking (`keyup`), and a functional arithmetic calculator handling addition, subtraction, multiplication, and division with error validation.
* **`todo.html` (Part 4 - Mini Project / To-Do App):** A fully interactive To-Do list manager. Features include adding new tasks, rendering items dynamically, toggling completion status with a strike-through effect, deleting individual tasks, and handling state persistence temporarily within a JavaScript array.
* **`style.css`:** Comprehensive stylesheet providing clean typography, responsive containers, consistent color schemes, and smooth transition effects.Open the project folder in your preferred code editor (e.g., Visual Studio Code or IntelliJ IDEA).
Open index.html in any modern web browser (Google Chrome, Safari, Firefox) directly, or use a local development server extension (like Live Server in VS Code).
